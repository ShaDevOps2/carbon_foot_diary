# Carbon Footprint Diary

SDG 13 Flutter Project 

## Main Goals of the Project
   
The Carbon Footprint Diary project aims to make personal carbon tracking accurate, understandable and visually engaging. Its main goals are:

1.	Provide easy daily carbon tracking: Enable users to record transportation, electricity, food, waste, water, household-fuel and shopping activities in a few clear steps.
2.	Calculate transparent carbon estimates: Convert activity data into kg CO2e using documented, region-appropriate and versioned emission factors, while showing users how results are calculated.
3.	Deliver a beautiful user experience: Use a modern nature-inspired interface, consistent components, accessible colours, responsive layouts, polished charts, light and dark themes and purposeful animations.
4.	Improve environmental awareness: Help users understand which daily activities and categories contribute most to their estimated footprint.
5.	Support measurable reduction: Allow users to define daily, weekly, monthly and category-specific goals and monitor progress against a baseline.
6.	Encourage sustainable behaviour: Provide personalized rule-based recommendations, reminders, challenges, streaks, points and badges without shaming users.
7.	Provide useful insights and reports: Present daily, weekly, monthly, yearly and custom-period trends and allow PDF and CSV exports.
8.	Ensure reliable administration: Allow administrators to manage users, categories, activities, emission factors, recommendations, educational content, badges and challenges.
9.	Protect user information: Apply secure authentication, role-based authorization, privacy controls, audit logging and account data export or deletion procedures.
10.	Create a maintainable platform: Use a modular architecture that can later support more countries, languages, categories, integrations and emission-factor datasets.
